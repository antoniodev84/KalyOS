Links, GET forms, external stylesheets and external scripts are supported.

Current subset

  • Headings, paragraphs, nested blocks, lists, links, buttons and text inputs.
  • Colors, backgrounds, margins, padding, widths, borders and two font sizes.
  • Variables, arithmetic, conditions, loops, functions and DOM text/style updates.

HTTP only: HTTPS needs TLS. Images display their alternative text. This is not a full web engine.
